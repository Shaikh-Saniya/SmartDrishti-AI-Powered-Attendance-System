About the Project

SmartDrishti (दृष्टि — meaning "vision") is an intelligent attendance management system designed for educational institutions. It leverages state-of-the-art face recognition technology to automate the tedious process of manual attendance marking.

Built with FastAPI, PostgreSQL with pgvector, and robust face matching, the system can detect and match multiple faces in a single group photograph, making it ideal for classrooms.
